# Technical Specification: DSE Web Admin Studio v10.0.41.07
## Comprehensive Quality Assurance, Layout Parity & Core Functionality Stabilization

**Target Web Version:** `10.0.41.07`  
**Desktop Baseline:** `10.0.41`  
**Web Build:** `7`  
**Target Web Tag:** `web-v10.0.41.07`  
**Compliance Authority:** `prinical.md` (Rules 1-14)  

---

## 1. Executive Summary & Root Cause Overview

This release addresses 10 critical functional defects, visual anomalies, and regression issues identified across Dashboard, Sales Register, Quotations, Bank & Expense modules, General Ledger, and Header Navigation:

1. **KPI Card Distortion After Refresh:** `KpiCardEnhancer.js` and `css/app.css` forced `height: 58px !important` and destructively overwrote inner card DOM (`card.innerHTML = ...`), crushing natural card proportions (Image 4 expected vs Image 5 corrupted).
2. **Master Lookup Parity for Charges & Bank Payments:** Dynamic additional charges in Sales/Purchase creation were disconnected from Master Lookups, and `RecordPaymentController` queried non-existent `'BANK_ACCOUNT'` instead of Master category `'BANK'`, leaving bank details stuck on "Loading...".
3. **Sales Register Purple Action Button Dead:** The actions menu markup (`#sales-row-actions-menu`) was misplaced in `views/sale-create.html` instead of `views/sales-register.html`, causing click handlers to return immediately.
4. **Attachment Panel Inconsistency:** `views/sale-create.html` utilized a compressed 1-line icon row instead of the standardized Desktop/Settings attachment panel with dropzone, preview, and `+ Add / Replace`, `👁 Preview`, `Delete` actions.
5. **Top Header Redundant Version Display:** Header badge `v10.0.41.06` next to branding is redundant since the version is already displayed inside the Profile action menu footer.
6. **General Ledger Freeze on Row Click:** Clicking a ledger record triggered drawer open and table reflow routines with unconstrained layout dimensions and unhandled exception paths.
7. **Table Workspace Empty Space Below KPI Cards:** Data panels in modules like Bank Entry failed to expand to 100% of the available vertical viewport height (`flex: 1`), leaving large dead spaces at the bottom.
8. **Permanent Unread Email Counter:** Header `#badge-email` remained stuck displaying unread count (e.g. `3`) because Communication Center lacked read-acknowledgment and count reset logic.
9. **Bank & Expense 5 Submenus Filter Wrap Defect:** `.form-input` and `.form-select` with `width: 100%` inside `flex-wrap: wrap` toolbars caused each search/filter element to stack on its own separate line instead of aligning in a single row.
10. **New Quotation (F3) Async Mount Race Condition:** `openQuotationEditor` called `NavigationRouter.selectNav` asynchronously without awaiting the external view mount, attempting to populate customer dropdown and date fields before `#view-quotation-editor` existed in the DOM.

## 2. Detailed Technical Remediation Plan

### Issue 1: KPI Cards Restoration & Desktop Visual Parity (Image 4 Parity)
- **Root Cause:** `css/app.css` line 3098 enforced `height: 58px !important; max-height: 58px !important;` on `.dash-kpi-card`, `.kpi-card`, and `.standard-kpi-card`. Furthermore, `KpiCardEnhancer.js` ran `enhanceCard()` destructively replacing card HTML, stripping IDs like `dash-kpi-sales-count` and corrupting layout.
- **Fix:** 
  1. Remove the restrictive `height: 58px !important` and ribbon-squashing constraints from `css/app.css`.
  2. In `KpiCardEnhancer.js`, preserve existing card markup and hierarchy. Never wipe out `.dash-kpi-card` or cards with structured metrics/badges. Ensure Image 4 remains identical before and after refresh.

### Issue 2: Additional Charges & Payment Bank Accounts & Paymentmode Master Lookup Integration
- **Root Cause:** `SalesController.js` hardcoded `availableChargeTypes`. `PurchaseController.js` had `availableChargeTypes` undeclared. In `RecordPaymentController.js`, `getLookupsByCategoryCode('BANK_ACCOUNT')` was queried, but Master Data registers categories under `'BANK'`.
- **Fix:**
  1. In `RecordPaymentController.js`, update lookup loader to query `'BANK'` with fallback to `'BANK_ACCOUNT'` and existing bank statement accounts.
  2. In `SalesController.js` and `PurchaseController.js`, dynamically load charge types from `MasterService.getLookupsByCategoryCode('CHARGES')` / `'CHARGE'` with fallback to standard freight/handling charges.

### Issue 3: Sales Register Purple Action Button Activation
- **Root Cause:** `#sales-row-actions-menu` was located inside `views/sale-create.html`. When on `views/sales-register.html`, `document.getElementById('sales-row-actions-menu')` returned null.
- **Fix:** Move `#sales-row-actions-menu` into `views/sales-register.html`, wire unified dropdown positioning, and ensure full click handling.

### Issue 4: Unified Attachment Panel Across Sales & Purchase Creation
- **Root Cause:** `sale-create.html` had a single-line input with plain icon buttons, while `settings.html` and `quotation-editor.html` have rich dropzones with clear action buttons.
- **Fix:** Standardize both `views/sale-create.html` and `views/purchase-creation.html` with:
  - Document dropzone card showing filename, file size, format icons.
  - Purple primary `+ Add / Replace` button.
  - Secondary `👁 Preview` button.
  - Red secondary `Remove` button.

### Issue 5: Top Header Version Badge Removal
- **Root Cause:** Redundant `#header-app-version-badge` displayed in the top header.
- **Fix:** Remove `#header-app-version-badge` from `index.html` header; retain version display cleanly inside the Profile dropdown menu footer.

### Issue 6: General Ledger Stability on Record Click
- **Root Cause:** `onGlRowClick` and `showGlDetails` in `FinanceController.js` triggered drawer expansion while `#gl-workspace` lacked proper split flex boundaries, and formatting utilities had missing guards.
- **Fix:** Add defensive checks in `showGlDetails`, ensure `#gl-workspace` split operates with `flex: 1` and `min-height: 0`, and wire escape key / backdrop dismiss handlers.

### Issue 7: Panel Expansion to Full Available Viewport Height
- **Root Cause:** Table workspaces in modules like Bank Entry collapsed to the height of their few items rather than filling the vertical height down to the bottom footer.
- **Fix:** Set `.register-workspace` and `.register-table-panel` to `flex: 1 1 auto; height: 100%; min-height: 0;` so the panel expands to bottom boundaries, enabling maximum visible rows and clean internal scrolling. Expand dashboard recent activities from 4 to 8+ records.

### Issue 8: Header Email Notification Counter Clearing
- **Root Cause:** Email badge (`#badge-email`) was never reset when user viewed messages in Communication Center.
- **Fix:** In `CommunicationController.js`, on loading/viewing messages, reset unread email count in DOM and localStorage (`dse_shell_counts`), applying `.zero` class so the badge hides cleanly.

### Issue 9: Single-Row Filter Toolbar in All 5 Bank & Expense Submenus
- **Root Cause:** Parent toolbars had `flex-wrap: wrap` while children `.form-input` and `.form-select` had default `width: 100%`.
- **Fix:** In `views/bank-entry.html`, `views/expense-entry.html`, `views/bank-statement.html`, `views/purchase-recon.html`, and `views/recon-supplier.html`, set toolbar to `display: flex; gap: 8px; align-items: center; flex-wrap: nowrap;` with `flex: 1` on search input and `width: auto; flex: none;` on dropdowns and dates.

### Issue 10: New Quotation F3 View Mount Synchronization
- **Root Cause:** `openQuotationEditor` did not `await window.NavigationRouter.selectNav('view-quotation-editor')`. It attempted to populate fields before `ViewLoader` finished asynchronous mounting.
- **Fix:** Make `openQuotationEditor` properly `await selectNav('view-quotation-editor')` and verify elements exist prior to populating defaults and bootstrap data.
