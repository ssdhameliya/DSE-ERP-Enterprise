### Issue 6: Purchase Recon Register System Ref, Date Format & Linked Bank Statement Navigation

#### Desktop Implementation
- **Source:** [PurchaseReconController.java](file:///c:/Users/JATIN%20DHAMELIYA/Downloads/DSE-ERP-10.0.25-INTELLIJ-READY-FINAL-V19/DSE-ERP-10.0.25/desktop/src/main/java/org/example/controller/PurchaseReconController.java#L9-L60)
- **System Ref:** Desktop binds `colRef` to `row.reference()` (e.g. `PREC/2026-27/0014`).
- **Date Format:** Desktop formats `invoiceDate` using `BusinessClock.formatDate()`.
- **Linked Reference:**
  - Evaluates `row.bankLinks()` (`List<BankLinkDto>`).
  - If empty or `linkedAmount <= 0.009`: displays `"—”`.
  - If 1 link: displays `preferredLinkReference(link)` (e.g. `HDFC/NEFT/12345` or `Bank #42`).
  - If multiple links: displays `preferredLinkReference(first) + " +" + (size - 1)`.
  - Tooltip shows all linked bank transactions with allocated amounts.
  - Clicking the link triggers:
    `LinkedRecordContext.open("BANK_STATEMENT", link.statementTransactionId().intValue(), link.bankReference(), "VIEW", "Purchase Recon " + row.reference())`
    and navigates to Bank Statement (`/fxml/pages/BankStatement.fxml`), highlighting the transaction!

#### Web Defect & Root Cause
- **Source:** [PurchaseReconController.js](file:///d:/ERP%20Website/admin/js/controllers/PurchaseReconController.js#L122-L130)
```javascript
<td style="font-weight:700; color:var(--cyan); font-family:monospace;">${r.systemRef || 'PRC-' + r.id}</td>
<td style="white-space:nowrap;">${formatDate(r.invoiceDate)}</td>
...
<td style="..." title="${r.linkedRef || ''}">${r.linkedRef || '-'}</td>
```
1. **System Ref:** The server DTO returns `r.reference`. Web looked for `r.systemRef`, which was undefined, so it always fell back to `'PRC-' + r.id` (e.g. `PRC-101`) instead of the real system reference (`PREC/2026-27/0014`).
2. **Date Format:** `formatDate(d)` had a local hardcoded string split `parts[2]/parts[1]/parts[0]`, bypassing `window.FormatUtil.formatDate()`.
3. **Linked Ref:** Server returns `r.bankLinks` (array), not `r.linkedRef`. `r.linkedRef` was always undefined, displaying `-`.
4. **Navigation:** Web lacked the click-through hyperlink from the linked reference to `view-bank-statement`.

#### Proposed Fix
1. In `PurchaseReconController.js`:
   Display `${r.reference || r.systemRef || 'PRC-' + r.id}`.
2. In `formatDate()`:
   Use `window.FormatUtil && window.FormatUtil.formatDate ? window.FormatUtil.formatDate(d) : ...`.
3. In `renderReconTable()`:
   Format `r.bankLinks` identically to Desktop:
   ```javascript
   function formatLinkedRef(r) {
     if (!r.bankLinks || r.bankLinks.length === 0) return '—';
     const first = r.bankLinks[0];
     const ref = first.bankReference || first.financeVoucherNo || (first.statementTransactionId ? `Bank #${first.statementTransactionId}` : 'Bank link');
     return r.bankLinks.length === 1 ? ref : `${ref} +${r.bankLinks.length - 1}`;
   }
   ```
4. Render as a clickable cyan badge/link. Clicking it invokes:
   `window.PurchaseReconController.openLinkedBankStatement(r)` which navigates to `view-bank-statement`, passes the linked transaction ID, and highlights the row!
