## 2. In-Depth Root Cause Analysis & Architectural Diagnosis

### 2.1 The Modal Scoping Trap
In `css/app.css` lines 599–604:
```css
body.light-theme #app-container .form-input, 
body.light-theme #app-container .form-select {
  background: #ffffff;
  color: #0f172a;
  border-color: rgba(148, 163, 184, 0.5);
}
```
In `index.html`, `<div id="app-container">` closes at **line 12121**. Every single modal and dialog in the entire application is declared **after line 12123**:
- Additional Charges (`#modal-manage-charges`)
- Create Sales Invoice (`#modal-new-invoice`)
- Universal Lightbox Preview (`#modal-universal-preview`)
- Customer & Party Modals (`#modal-new-customer`, `#modal-party-contact`)
- Master Data Entry Modals (`#modal-add-lookup`, `#modal-add-category`)
- User Provisioning Modals (`#modal-add-user`, `#modal-edit-user`)

Because the CSS rules were prefixed with `#app-container`, **zero modals received light theme rules**. Furthermore, raw `<input>`, `<select>`, `<textarea>`, `.filter-input`, and `.omni-search` do not have the class `.form-input` or were overridden by dark classes.

### 2.2 The Universal Focus Ring Defect
In `css/app.css` lines 3367–3376:
```css
.erp-input-active-focused,
input:focus:not([type=checkbox]):not([type=radio]),
select:focus,
textarea:focus {
  outline: none !important;
  border-color: #38bdf8 !important;
  box-shadow: 0 0 0 2px rgba(56, 189, 248, 0.35), 0 0 12px rgba(56, 189, 248, 0.25) !important;
  background: rgba(15, 23, 42, 0.95) !important;
  transition: border-color 0.15s ease, box-shadow 0.15s ease;
}
```
The declaration `background: rgba(15, 23, 42, 0.95) !important;` applies to **every input, select, and textarea across the application on focus**. When the user enters any field in Light Mode, the background immediately turns pitch black while the text color remains dark slate, resulting in illegible black-on-black text during data entry.

### 2.3 Action Dropdown Cascade Collision
In `css/app.css` lines 1019–1025:
```css
.actions-dropdown-menu,
.action-dropdown-menu {
  position: fixed !important; z-index: 100005 !important; background: #0b1324;
  ...
}
```
Because this rule is declared later in the stylesheet than line 632, it overrode `body.light-theme .actions-dropdown-menu`. Furthermore, controllers (`FinanceController.js`, `BarcodeStudioController.js`) had inline styles `style="background:#0b1324;..."`. In Light Mode, `.actions-menu-item` had `color: #0f172a;`, rendering black text on a pitch black floating card.

### 2.4 Master Data Viewport Compression
In `index.html` line 4271:
- Left categories panel: fixed `width: 320px;` and inline `background: rgba(15, 23, 42, 0.7);`
- Middle lookup values table: `flex: 1; min-width: 0;`
- Right detail drawer: `width: 380px;`
On a standard 1366px display, `1366px - 60px (sidebar) - 320px (left rail) - 380px (drawer) - 60px (margins)` leaves only **~540px** for 7 table columns, causing table header text ("LOOKUP CODE", "DISPLAY NAME") to be severely clipped.
Additionally, `max-height: 480px;` plus header and buttons exceeds the available stage height on standard screens, causing "Rename" and "Deactivate" buttons to overlap the bottom footer.

### 2.5 Table Viewport Locking in Non-Standard Layouts
In `css/app.css` line 3002:
`main.app-stage:has(.module-view.fixed-viewport.active)` applies `overflow: hidden !important;`.
While standard registers (`#view-sales-register`, `#view-purchase-register`) have `.register-workspace` with flex scrolling, non-standard fixed views like `#view-financial-statements` contain stacked cards (Revenue KPIs + Balance Sheet strip + Health Ratios + Tab Navigation = ~380px) followed by `.fs-tab-panel`. Because `.fs-tab-panel` and `.table-container` lacked `flex: 1; min-height: 0; overflow-y: auto;`, and the outer stage was locked to `overflow: hidden`, table rows below the fold were completely unreachable.

## 3. Centralized Solution Architecture

### 3.1 Centralized Light Theme Tokens & Form Controls
All light mode rules will be consolidated into a dedicated, clean, centralized block in `css/app.css` using universal element selectors and `!important` overrides where necessary:
```css
/* ==========================================================================
   CENTRALIZED LIGHT THEME ENGINE (v10.0.38.03)
   Comprehensive UI Modernization & High-Contrast Readability
   ========================================================================== */
body.light-theme {
  --bg-dark: #f8fafc;
  --bg-surface: #ffffff;
  --bg-card: #ffffff;
  --bg-elevated: #f1f5f9;
  --bg-base: #f8fafc;
  --border-subtle: #cbd5e1;
  --border-focus: #0284c7;
  --text-main: #0f172a;
  --text-muted: #334155;
  --text-dim: #64748b;
  color: #0f172a;
  background-color: #f8fafc;
  color-scheme: light;
}

/* Universal Inputs, Dropdowns, Date Pickers, Textareas */
body.light-theme input:not([type="checkbox"]):not([type="radio"]):not([type="submit"]):not([type="button"]),
body.light-theme select,
body.light-theme textarea,
body.light-theme .form-control,
body.light-theme .form-input,
body.light-theme .form-select,
body.light-theme .filter-input,
body.light-theme .filter-select,
body.light-theme .omni-search,
body.light-theme .search-input {
  background: #ffffff !important;
  color: #0f172a !important;
  border: 1px solid #cbd5e1 !important;
}

/* Neutralize Black Focus Bug */
body.light-theme input:focus:not([type="checkbox"]):not([type="radio"]),
body.light-theme select:focus,
body.light-theme textarea:focus,
body.light-theme .form-input:focus,
body.light-theme .filter-input:focus,
body.light-theme .omni-search:focus {
  background: #ffffff !important;
  color: #0f172a !important;
  border-color: #0284c7 !important;
  box-shadow: 0 0 0 3px rgba(2, 132, 199, 0.2) !important;
}

/* Native Select Options */
body.light-theme select option {
  background: #ffffff !important;
  color: #0f172a !important;
}

/* Date Picker Calendar Indicator */
body.light-theme input[type="date"]::-webkit-calendar-picker-indicator {
  filter: none !important;
  opacity: 0.8;
  cursor: pointer;
}

/* Readonly & Disabled Inputs */
body.light-theme input[readonly],
body.light-theme textarea[readonly],
body.light-theme input:disabled,
body.light-theme select:disabled {
  background: #f1f5f9 !important;
  color: #475569 !important;
  border-color: #e2e8f0 !important;
  cursor: default;
}
```
