## 3. Detailed File Modification Plan

### 1. `d:\ERP Website\admin\js\util\TableUiEnhancer.js`
- Add `enhance(target)` alias method to `TableUiEnhancer`:
  ```javascript
  enhance: function(target) {
    if (!target) return;
    if (target.nodeName === 'TABLE') return this.enhanceTable(target);
    return this.enhanceAll(target);
  }
  ```
